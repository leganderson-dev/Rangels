# Rangels V0.11 — Household allocation reporting

V0.11 turns the Plan page into a reporting surface for the shared Household allocation model.

It adds:

- visual eligible-income plumbing into Daily Expenses, Splurge, Smile, and Fire Extinguisher;
- selected-month target, actual use, and movement reporting;
- year-to-date allocation movement;
- Anderson, Julia, and Joint attribution based on account ownership;
- a separate summary of Purpose budgets;
- explicit warnings wherever opening balances or immutable allowance-ledger data are not yet available.

The page deliberately does not label derived year-to-date movement as an authoritative available allowance. True personal balances still require opening entitlements, member split rules, automatic allocation credits, and audited allowance movements.
