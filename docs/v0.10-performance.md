# Rangels V0.10 — Ledger performance

V0.10 keeps Supabase as the authoritative datastore while removing repeated full-ledger downloads from ordinary navigation and transaction saves.

- Account balances and account-period summaries are calculated by indexed PostgreSQL functions.
- Purpose counts are aggregated in PostgreSQL.
- Transaction queries retrieve only the selected period and required columns.
- Period, classification, account metadata, and member reference queries are cached in memory.
- Local writes invalidate transaction caches before authoritative records are reloaded.
- Adjacent months are prefetched after the active month loads.
- Transaction search is debounced to avoid a network request for every keystroke.

The migrations modify indexes and add read-only aggregate functions. They do not rewrite financial transactions.
