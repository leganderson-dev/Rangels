# Rangels V0.13 — Flexible schedules

V0.13 expands scheduled transactions with explicit recurrence rules:

- daily intervals such as every 3 days;
- weekly intervals with one or more selected weekdays;
- monthly schedules with a day of month and selected months;
- optional end dates;
- virtual schedules that contribute to forecasts but never create ledger entries.

The start date is also the first next-run date. Processing a due non-virtual schedule creates its classified transaction and advances it to the next valid occurrence. Processing a virtual schedule only advances its date. When the following occurrence exceeds the optional end date, the schedule becomes inactive.
